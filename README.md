JavaScript and Data Structures Practice Repository

A structured codebase documenting daily practice in core JavaScript (ES6+) and foundational Data Structures and Algorithms (DSA) as part of full-stack MERN engineering preparation.

Repository Structure

Core Fundamentals (/variables, /operators, /conditional)
Data types, expressions, and control flow logic.

Iteration and Control (/loop, /foreach, /loopsFunction)
Standard loop constructs and iteration patterns.

Functions and Scope (/function, /mainFunction)
Function declarations, return values, and callback execution.

Data Structures (/arrays, /objects)
Object modeling and array operations.

Higher-Order Array Methods (/map, /find-some-every, /ArrayForEach)
Functional array transformations and predicate checks including map, filter, reduce, find, some, and every.

Algorithms and Problem Solving (/DSA)
- ReverseAnArray: Array reversal without built-in helper methods.
- string-reveral-palindrome: Case-insensitive string reversal and palindrome verification.

Technical Stack

- Environment and Version Control: Node.js, Visual Studio Code, Git, GitHub
